# Marketing website

## Location
`website/` — static pixel-art landing page (Sweetie 16, Press Start 2P, VT323).

## Messaging rules
- **Show:** quest board, pool, XP, streak, loot shop wishlist, character, quest log, direct APK download.
- **Hide:** vault, Pix, money, subscriptions billing, roadmap phases, wallet waitlist.
- **Future section:** vague only — "big ideas forging ahead", no spoilers.

## Files
- `index.html`, `styles.css`, `main.js`
- `assets/sprites/loot/` — synced from app
- `downloads/questvault.apk` — add release build to enable download button

## Pencil
`design/s10-landing.js` — landing screen mock in `questvault.pen`

## Preview
```powershell
cd website
npx --yes serve .
```
