# Web app (PWA) build output

This folder is generated by:

```powershell
node website/scripts/build-pwa.mjs
```

After building, users install QuestVault from **`/app/`** (not the marketing homepage).

## Requirements for install

- **HTTPS** in production (localhost is OK for dev)
- User must visit `/app/` at least once
- Chrome/Edge/Android: browser shows install prompt or use the in-app **INSTALL** banner
- iOS Safari: Share → **Add to Home Screen** (no automatic prompt)

## Do not commit?

Large build artifacts — add to `.gitignore` if you prefer CI builds only. Keep this README.
